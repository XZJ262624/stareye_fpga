## 推荐路线与兼容边界

**候选推荐：使用现有 Efinity 2025.1.110 主程序，随后按配套说明应用 2025.1.110.5.9 补丁。版本路线待用户确认。** 该建议利用现有介质及官方器件支持；不能据此写“HDK 全部示例兼容”。

[官方 Efinity 用户指南 v16.1（2025-06）](https://www.efinixinc.com/docs/efinity-ug-v16.1.pdf)：
- 文件第 9 页的支持表含 Ti60F225。
- 第 11 页提示旧工程升级会更新版本/模型文件；应使用工程副本保留原版。
- 第 44、115 页说明 2025.1 的新 JTAG 桥替代旧 JTAG_SPI Flash Loader，新桥供 2025.1 及以上 Programmer 使用。不能混用旧 HDK 桥和新 Programmer。

本地 HDK 证据：
- 版本备注 V1.6 记载升级到 2023.1；分类目录名“2023.2”不代表全部 XML 使用同一版本。
- LED XML 保存版本 2023.2.307.5.10；已读 HDMI、AR0135 和旧下载桥 XML 保存版本 2023.1.150.3.11。
- V2.1 新增 SC1336 ZIP 的内部版本未核对。
- 若优先原版复现，匹配所选 XML 的旧版本可作为另一条路线；是否获取旧工具**待用户确认**，不把它写成必须安装。
- 资料没有直接证明 Ti60 HDK 对 2025.1.110+5.9 的整包兼容。工程导入、IP 更新、器件/时序模型、综合和实际下载均未验证。
- 手册 I3 与示例 timing_model=C4，以及 DDR 型号/容量差异，见 SOURCES.md；需按实物复核，不能自动采用示例设置。

## 后续建议安装顺序（本轮不执行）

1. **先确认安装前置条件。** 确认当前 Windows 版本与 64 位架构、内存/磁盘资源、安装目录和权限、介质来源，以及官方下载账号/许可。本地 2021 年安装指南较旧，不能据它承诺当前系统受支持；当前系统与 2025.1 要求匹配情况**待用户确认**。[国内官方下载入口](https://www.elitestek.com/efinity/)提供账号/下载资格申请信息。
2. **再安装主程序及补丁。** 用户确认候选路线后才运行主 MSI。根据 patch_readme：主程序安装完成后，后续在 CMD 中加载安装目录 bin/setup.bat，再进入补丁目录运行 run.bat 并按提示处理。这里只记录顺序，没有执行。安装结束核对实际主程序/补丁版本及许可；若重新使用旧结果，补丁说明中的时序修复要求应纳入后续重跑检查。
3. **最后按硬件识别处理驱动。** 用户实物/设备管理器硬件 ID 核对后，才选择匹配的 FPGA 下载器驱动。UART 驱动仅在使用串口且确认串口硬件后评估。RISC-V IDE 暂缓。后续样例验证需另获进入 M0 的指令，再选工程副本；本轮不开展点灯。

驱动区分：
- 资料包的 ELITES-232DL.inf 对应 VID_0403&PID_6014，使用 libusbK；这是随包驱动目标，并未确认用户实际下载器就是该型号。
- 底板原理图 U7 标注 CH340N，是 USB UART；不能把它当 FPGA JTAG 下载器。
- CH340N 目录内 CH341SER.EXE 只是文件名，不能据此建议安装 CH341 驱动。本轮未运行任何驱动安装程序，不给出未匹配硬件的安装建议。
