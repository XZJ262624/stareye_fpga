# 星眸项目背景

## 已确定背景

- 项目名称：星眸多算子边缘感知系统。
- 比赛：2026全国大学生嵌入式芯片与系统设计竞赛FPGA赛道。
- 平台：易灵思VF-Ti60F225（实物核心/底板V1.5用户确认；相机已连接且新I3基础链路已验收；电气/冷启动隔离仍待专项核查）。
- 路线：摄像头采集→灰度化→滤波→边缘检测→HDMI显示。
- 扩展：多算子切换、自适应阈值、彩色叠加、OSD、延迟与资源测试。
- 用户具备OpenCV、Linux基础和视觉应用经验。
- 用户尚未系统掌握FPGA、Verilog、视频流水线、跨时钟域和行缓存。
- 操作指导应先解释目的，一次只给1～3个实际操作，再根据真实反馈继续。

M0/M1/M2基础链路实物PASS；M2新Ti60F225I3经用户JTAG临时下载，AR0135实时图像、1280×720@60Hz、连续10～15分钟定性正常。M3 Sobel实物功能PASS、图像质量待调优；M3.1控制与阈值和M3.2中值滤波已独立归档。AR0135输出为单色8位流。M4灰度背景+中心对齐红色边缘叠加已完成离线仿真、完整I3编译、STA和实物功能验收PASS，保留已知首行异常；M5～M7未开始，后续范围与其余需求待确认。M3独立工程来自M2已编译69文件快照，未覆盖GUI再生成的M2工作输入。短时基础链路和离线算法PASS不代表DDR全面压力/全容量/温度/校准、CDC/复位、电气或冷启动认证；旧Flash R3/R4风险和既有告警保留。详见STATUS及M3 BUILD_REPORT。
