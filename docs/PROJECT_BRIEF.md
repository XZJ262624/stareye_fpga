# 星眸项目背景

## 已确定背景

- 项目名称：星眸多算子边缘感知系统。
- 比赛：2026全国大学生嵌入式芯片与系统设计竞赛FPGA赛道。
- 平台：易灵思VF-Ti60F225（实物核心/底板V1.5用户确认；相机已连接且新I3基础链路已验收；电气/冷启动隔离仍待专项核查）。
- 路线：摄像头采集→灰度化→滤波→边缘检测→HDMI显示。
- 扩展：多算子切换、自适应阈值、彩色叠加、OSD、延迟与资源测试。
- 用户具备OpenCV、Linux基础和视觉应用经验。
- 用户尚未系统掌握FPGA、Verilog、视频流水线、跨时钟域和行缓存。
- 操作指导应先解释目的，一次只给1～3个实际操作，再根据真实反馈继续。

## 当前范围

M0基础验收通过并提交；旧Flash官方流水灯不能证明当前I3 bit持久性。M1独立HDMI基线PASS，参考目标1080p60，其显示器读数仍未补充。M2新Ti60F225I3相机→DDR→HDMI基础链路PASS：离线构建/已约束STA通过，用户确认JTAG临时下载、AR0135实时图像、显示器识别1280×720@60Hz、连续10～15分钟正常且运动持续更新，无黑屏/闪屏/花屏/冻结/明显撕裂；未SPI Active/Flash。灰度化延期，M3～M7未开始；其余需求仍待冻结。短时基础链路PASS不代表DDR全面压力/全容量/温度/校准信号、CDC/复位、电气或冷启动认证，旧Flash R3/R4风险及告警保留。当前工程XML和附带IP存在再生成差异，不能宣称全部当前工作区输入等于既有已编译构建；见STATUS与验收报告。
