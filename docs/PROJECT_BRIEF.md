# 星眸项目背景

## 已确定背景

- 项目名称：星眸多算子边缘感知系统。
- 比赛：2026全国大学生嵌入式芯片与系统设计竞赛FPGA赛道。
- 平台：易灵思VF-Ti60F225（目标平台；实际板卡版本及连接待确认）。
- 路线：摄像头采集→灰度化→滤波→边缘检测→HDMI显示。
- 扩展：多算子切换、自适应阈值、彩色叠加、OSD、延迟与资源测试。
- 用户具备OpenCV、Linux基础和视觉应用经验。
- 用户尚未系统掌握FPGA、Verilog、视频流水线、跨时钟域和行缓存。
- 操作指导应先解释目的，一次只给1～3个实际操作，再根据真实反馈继续。

## 当前范围

M0基础验收通过并提交；断电流水灯不能证明当前I3 bitstream持久性，因为用户此前固化过官方例程。M1独立HDMI工作副本以Ti60F225I3/Efinity2025.1.110.5.9完成离线编译与数据时序检查，厂商六份RTL保持逐字不变。用户确认M1独立HDMI JTAG临时下载显示正常、约几分钟无异常，独立HDMI基线PASS；显示器识别分辨率/刷新率待确认。PLL LOCKED异步复位、失锁恢复和长期稳定性仍待专项验证；摄像头直通未验收，不接入AR0135、不Flash、不新增算法RTL。其余需求继续在P0记录。
