# 星眸项目背景

## 已确定背景

- 项目名称：星眸多算子边缘感知系统。
- 比赛：2026全国大学生嵌入式芯片与系统设计竞赛FPGA赛道。
- 平台：易灵思VF-Ti60F225（目标平台；实际板卡版本及连接待确认）。
- 路线：摄像头采集→灰度化→滤波→边缘检测→HDMI显示。
- 扩展：多算子切换、自适应阈值、彩色叠加、OSD、延迟与资源测试。
- 用户具备OpenCV、Linux基础和视觉应用经验。
- 用户尚未系统掌握FPGA、Verilog、视频流水线、跨时钟域和行缓存。
- 操作指导应先解释目的，一次只给1～3个实际操作，再根据真实反馈继续。

## 当前范围

P0 项目骨架与文件化交接初始化；不进入 M0，不生成摄像头、HDMI、灰度化、滤波、Sobel 或其他算法 RTL。
