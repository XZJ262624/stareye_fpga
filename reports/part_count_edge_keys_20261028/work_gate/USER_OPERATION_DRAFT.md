# 可调阈值计件版操作草案（尚未放行上板）

默认H048/L024、RAW。板K1单次短按降低H8，板K2单次短按提高H8；L随H减半。H范围8～128，到上下限不绕回。双键短按仅RAW/MSK切换；MSK沿用实际用于计件的closing后白色边缘。双长沿用历史诊断重新布防，具体以最终验证结果为准。阈值不写Flash，断电/重新配置恢复默认48/24。

之后实物测试时先在相机、背景、灯光不变条件下用MSK观察原失败六颗，从48按K1逐步试40、32、24、16、8；每档移开手与阴影并等待新的CURRENT，记录边缘是否闭合、实际6是否CURRENT06。降低阈值可能同时增加杂边，不保证最低值最好。确认后再做6→5→4→3→4→5→6，不能只看错误码消失或LAST旧数。

改变阈值会撤销旧CURRENT并重新按原三次独立camera结果确认；LAST只表示历史。RAW/MSK切换不改变阈值、不重设确认。不重新引入E4/E5残边/边距或E9亮度资格检查。容量、数据完整性和原几何算法边界继续保留。

本草案不构成下载授权。完成必要自检、构建和Work冻结后先交用户独立Codex A，用户返回审查结果后另给指定BIT、SHA与实物清单。
