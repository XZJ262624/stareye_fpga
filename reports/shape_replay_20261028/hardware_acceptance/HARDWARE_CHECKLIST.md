## 2. 按键（板上物理K1/K2）

| 按法 | 功能 |
|---|---|
| K1短按，LIVE时 | 开始REC；旧片段立即失效 |
| REC自动录满32幅 | 自动PLAY循环 |
| K1短按，PLAY/PAUSE时 | 暂停/继续；在途整帧可以先结束 |
| K1长按约1秒 | 返回LIVE；在REC时取消未完成录制 |
| K2短按 | COV→RAW→CNY→COV |
| K2长按约1秒，LIVE时 | 从头重播已完成片段；无片段则保持LIVE |

短按后完全松开，建议间隔约0.2秒；长按触发门约0.6秒，操作时按约1秒。不要同时按两键，两键交叠会被抑制。

**已披露P2：正常REC期间只等待，不额外短按K1或长按K2。** 这些本应不改变状态的按法若恰好遇采样边界，可能将一次4帧采样间隔推迟成5帧。本轮未修复，不以本次录像证明这些按法无影响。仅取消专项明确使用K1长按。

## 3. 基础检查

1. 出图后松开两键，确认LIVE、默认COV/H64/L32、绿色960×540框、ABC123左右与上下方向正常。
2. 圆形稳定放入框内，观察PREV CIRCLE；换轴对齐矩形，观察PREV RECT。各测试3次；空白及三角形应UNKNOWN。PREV为上一显示帧的结果，切换后可短暂UNKNOWN。
3. K2短按依次检查RAW灰度、CNY白边、COV灰度叠加红边，绿色框和分类文字正常；回COV继续。

## 4. 录制、历史来源与暂停

1. LIVE时放好圆形，确认可识别；可缓慢在框内平移一点，避免出框或遮住轮廓。
2. K1短按进入REC，等待计数走到32并自动PLAY；这一段不按其他键。名义片段约2.1秒，实际按键至完成的时间需记录，不要求精确2.125秒。
3. PLAY时将真实场景换成矩形或空白。屏幕应继续循环刚录的圆形图像及其历史分类，而非跟随现在的相机；回放帧号应循环。缓慢平移片段应重复原动作，不应出现错序、撕裂或混入当前矩形。
4. K1短按PAUSE，帧号及历史画面应保持；移动真实纸张不应改变暂停图。再K1短按继续，帧号重新前进。暂停/继续做3轮，确认连续短按没有误变LIVE。
5. PLAY时也可K2短按检查三视图，图像仍来自同一历史片段。分类可能随视图上下文切换先UNKNOWN再恢复，不能长期错误或不恢复。
6. K1长按返回LIVE，应看到真实当前矩形/空白及对应后续分类；完整片段仍保留。LIVE时K2长按，应从第1幅重播已有圆形片段。

## 5. 替换片段与取消

1. 回LIVE，放矩形并确认RECT；K1短按重新录制，REC期间等待自动完成。PLAY后移走矩形/换圆形，历史图像及分类应仍是新录的矩形，旧圆片段不应混入。
2. 取消专项：回LIVE后开始一次新REC，确认尚未到32时立即K1长按约1秒取消，应回LIVE/NO CLIP。若来不及、已录满再回LIVE，则该项未覆盖，重新尝试。
3. 取消后LIVE时K2长按，应保持LIVE，不能复活已部分覆盖的旧片段。再完整录一次，应能正常播放。
4. 最后运行观察约5分钟，包含录放、暂停/继续和返回LIVE；记录黑屏、花屏、撕裂、错列、冻结、重启、ERROR及发生步骤。发生异常先保留屏幕完整文字/场景，拍照片或短视频，不反复重试覆盖现场。
