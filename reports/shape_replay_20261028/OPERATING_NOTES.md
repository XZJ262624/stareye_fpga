# 回放＋简易形状识别专用演示版

本版把历史灰度图重新送入与LIVE相同的GAU2、局部Canny和圆／轴对齐矩形识别链。不是计件版，也没有全局BFS或历史融合。新BIT须经用户独立Codex A审查，再由Work明确给出实物清单；本文件不是下载许可。

## 操作

| 操作 | 行为 |
|---|---|
| 上电／重新配置 | LIVE，默认COV（灰度＋红色局部边缘），释放两键后接受操作 |
| K1短按，LIVE时 | 开始新录制，立即撤销旧片段，显示REC及已完整写入的帧数 |
| 录满32幅 | 自动PLAY循环播放历史片段 |
| K1短按，PLAY／PAUSE时 | 暂停／继续；在途完整帧可先结束，暂停后持续刷新同一历史帧 |
| K1短按，REC时 | 不另触发操作；需要取消时长按 |
| K1长按约0.6秒 | 返回LIVE；完整片段保留，未完成录制取消后片段无效 |
| K2短按 | COV→RAW→CNY→COV，帧边界切换视图 |
| K2长按约0.6秒，LIVE时 | 从头重播已有完整片段；无片段时保持LIVE |
| 两键交叠 | 抑制按键操作，全部释放后再操作 |

阈值固定H64／L32，GAU2固定；本版按键不再调阈值。RAW显示灰度，CNY显示白色局部边缘，COV显示灰度和红色局部边缘。上方保留PREV CIRCLE／RECT／UNKNOWN，第二行显示LIVE／REC／PLAY／PAUSE、录制进度或回放帧号、CLIP或NO CLIP。绿色框为960×540识别ROI。

PREV是上一显示帧的结果，不能当作当前像素的零延迟识别。LIVE与历史源切换、视图切换时撤销旧上下文结果，等待新帧结果。回放和暂停重复同一capture ID是合法的；每个显示帧仍有独立display序号，帧内像素、身份和完整性检查保留。

## 片段与边界

记录32幅完整1280×720灰度图，8bit／像素，有效载荷29,491,200字节。每4个相机帧选1幅，配置推算约15.06幅／秒、约2.1秒动作；首幅与末幅时间戳相隔31个采样周期，约2.058秒。相机实际帧率、自动曝光影响及按键至首个完整帧的等待时间须实物确认。HDMI目标60Hz，每幅完整消费4次后再前进，名义循环周期约2.133秒；缺乏服务时不能承诺精确墙钟节奏。

片段存于DDR的32–64MiB范围内，4个实时slot仍位于0／4／8／12MiB。PLAY和PAUSE期间相机继续写实时slot，历史区不写。只有真实最后B响应和合法完整camera EOF都到达，记录帧才登记；32幅全部完整才发布片段。新录制中途取消不能恢复已被覆盖的旧片段。

识别仍为单目标、圆和轴对齐矩形；原80..440尺寸域、ROI内16px余量及UNKNOWN规则保持。没有增加旋转、多目标、螺丝计件或抗条纹能力。协议／FIFO硬故障显示ERROR并停止DDR数据活动，继承只允许冷重新配置恢复的边界；不承诺热复位恢复。

本轮离线证据不能替代新片段地址区、实际帧率、实际图像效果、PVT、电气、长期稳定性及上板验收。没有执行Programmer、JTAG下载、SPI Active或Flash。
