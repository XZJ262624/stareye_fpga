# M5A流式局部Canny / Canny-lite算法规格

本阶段实现原始灰度→可选3×3中值→Sobel→四方向量化→3×3 NMS→双阈值→3×3局部连接。默认构建启用中值。RAW及两类叠加背景始终取原始灰度，未经过中值。输入是既有1280×720、1650×750光栅，实际PLL像素时钟74.4MHz；未改变相机、DDR、FIFO、PLL、复位来源、管脚或分辨率。

**局部3×3连接只完成强边缘邻域内的一跳弱边缘保留，不等价于完整全局Canny的递归/迭代滞后连接。** 没有整帧传播、DDR连通迭代、快慢融合或目标识别。

## 中值与梯度

中值使用已验收M3.2的九层奇偶排序网络及同一窗口算法，新M5A专用副本增加CE；旧源码不改动。中心3×3窗口记为p00..p22，行号向下递增。

`Gx=(p02-p00)+2*(p12-p10)+(p22-p20)`；`Gy=(p00-p20)+2*(p01-p21)+(p02-p22)`。

Gx/Gy为signed11，实际范围−1020..1020；Gy正值指向图像上方。内部MAG为unsigned12的`abs(Gx)+abs(Gy)`，保留完整幅值。独立枚举8个周边像素0/255顶点的凸函数最大值为1530（两个梯度独立上界相加2040不是同一个窗口可达最大值）。旧MAG和显示NMS映射为`min(MAG,255)`，旧BIN按饱和8位MAG比较原阈值；NMS比较使用未饱和12位幅值，避免强边缘被压成255平台。

## 四方向与临界角

令a=abs(Gx)，b=abs(Gy)，按顺序判定：

| 编码 | 精确条件 | NMS负侧 / 正侧 |
|---|---|---|
| 0：0° | `256*b <= 106*a` | 左 / 右 |
| 2：90° | 第一条不成立且`256*a <= 106*b` | 上 / 下 |
| 1：45° | 前两条均不成立，Gx/Gy同号 | 右上 / 左下 |
| 3：135° | 其余情况，Gx/Gy异号 | 左上 / 右下 |

零向量归0；等号分别归0°/90°。106/256近似tan(22.5°)，分界为22.492611899°和67.507388101°，误差约±0.007388101°。106倍采用64+32+8+2的移位加法；先扩展到19位再运算，包含端口极值−1024也不溢出。Gy朝上、图像Y朝下，因此同号梯度沿右上/左下，不能按Y向下梯度符号直接反用45/135编码。没有除法、反正切或乘法DSP。

## NMS平台、双阈值与局部连接

有完整有效3×3梯度邻域时，保留`center > negative_neighbor && center >= positive_neighbor`；其余输出0。常值平台内部全部抑制，平台负侧边缘按固定方向保留，规则与梯度符号正负无关，保证确定性。方向取窗口中心，不能取最新右下像素。正/负侧按上表定义。

`high=现有8位可调阈值`、`low=floor(high/2)`，默认64/32。NMS=0始终非边缘，包括high=0。非零NMS≥high为强；low≤非零NMS<high为弱；其余非边缘。阈值直接比较12位L1幅值（high补零扩展），显示饱和不参与NMS峰值判断。high≤255，超过255的非零NMS均属于强边缘。旧BIN/OVERLAY保持原有单阈值`MAG8>=threshold`，threshold=0的有效平坦窗口仍通过，未偷偷替换成Canny零幅值规则。

局部连接输出：`full_support && (center_strong || (center_weak && any_of_eight_neighbors_strong))`。八邻域来自原双阈值强分类，Canny输出不回灌。强→弱→弱长链只保留强及相邻第一弱点，远端弱点不递归传播。窗口有效条件为九个输入支持位全部有效；帧重启/复位以计数及有效位排除未填满RAM，无需清零RAM内容。

## 空间支持边界

令r=中值启用时2、旁路时1。对中心算法，Sobel/旧OVERLAY支持`r<=x<W-r && r<=y<H-r`；NMS支持半径r+1；Canny支持半径r+2。默认最终半径4：`4<=x<=1275 && 4<=y<=715`，组合需要最多9×9真实上下文；旁路最终半径3（7×7）。其来源是中值、Sobel、NMS、连接四个独立3×3窗口逐级各扩大一圈，并非只引用一个9×9名称。

RAW全活动画面显示。旧MAG/BIN保留M4右下槽位习惯：显示slot(x,y)对应中心(x−1,y−1)，启用时支持`3<=x<=1278 && 3<=y<=718`；旁路`2<=x<=1279 && 2<=y<=719`。旧OVERLAY已经是中心对齐，与旧MAG/BIN的槽位范围不可混淆。NMS/CANNY无支持边界显示黑色；OVERLAY/CANNY_OVERLAY无支持处只显示原RAW，不能出现伪红色。OSD始终最高优先级。
