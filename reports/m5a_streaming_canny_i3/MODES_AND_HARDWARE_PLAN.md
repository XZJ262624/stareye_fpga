# 七模式与历史实物验收计划

本文件保存离线阶段制定的模式说明与验收计划，不是逐项实物结果。用户已在2026-10-07明确M5A实物功能总体PASS，阶段状态更新为M5A PASS，详见[实物报告](HARDWARE_ACCEPTANCE.md)。用户未另给分模式、日志、照片或精确时长等细节，以下计划不倒填为已经逐项记录的现场观察；本轮不安排再次下载或测试。

启动BIN、高阈值64/低阈值32。双键有重叠按下后等全部释放，只产生一个模式事件；按顺序RAW→MAG→BIN→OVERLAY→NMS→CANNY→CANNY_OVERLAY→RAW。单独K1按下释放高阈值+16，单独K2−16，范围0..255饱和；低阈值自动右移1。长按无连发；抖动/短脉冲被20ms（1488000像素拍）消抖过滤。模式和阈值只在帧边界提交，重叠手势不改待提交阈值，启动按住需先全部释放。

| 编码/OSD | 显示 |
|---|---|
| 0 RAW | 原始灰度，完整活动画面 |
| 1 MAG | 原M4饱和Sobel幅值，保留旧slot语义 |
| 2 BIN | 原M4单阈值二值Sobel |
| 3 OVR | 原RAW背景+原中心Sobel纯红边缘 |
| 4 NMS | NMS未饱和比较后，显示饱和灰度 |
| 5 CNY | 一跳局部Canny黑白图 |
| 6 COV | 原RAW背景+中心对齐Canny纯红边缘 |

旧四模式OSD保持原矩形x12..147、y12..33及`RAW/MAG/BIN/OVR Tddd`像素。新增模式扩展到x12..227，显示`NMS/CNY/COV Hddd Lddd`；黑底白字高于红边缘和灰度图。0阈值Canny零幅值保持黑色；旧BIN/OVR保留原inclusive语义。

以下为实物签收前的历史计划，保留以解释原验收范围：

1. 核对交付bit完整路径/大小/SHA，再由用户进行临时JTAG下载；先确认BIN64启动与显示器720p60。此离线任务未授权执行实际连接/下载。
2. 七模式完整循环、正反释放顺序、独立K1/K2、长按；检查H/L自动一半、0/255饱和及帧边界变化无撕裂。确认旧RAW/MAG/BIN/OVR与已签收M4视觉一致。
3. 对水平/垂直/两斜向宽边缘查看MAG→NMS变细；NMS→CNY观察低对比弱边缘只在强邻域保留；COV纯红且背景原灰度、OSD可读、画面四周无伪红或旧帧残留。
4. 静态与挥手动态、多阈值和模式切换、持续运行，记录实际运行时长、显示器读数及异常。可确认当前条件功能，不能据此宣称跨全部PVT稳定。

当前首行例外：厂商固有首行异常不属于M5A新增回归，不阻断M5A验收。用户已明确该问题为厂商生产/参考链路的固有问题，不影响竞赛考核，无需继续处理；本轮未诊断、未修改RTL掩盖，也不声称M5A解决了该问题。旧Flash/R3/R4共享风险、PLL异步复位/失锁恢复、DDR压力与外围I/O边界保持。全局递归Canny尚未实现。
