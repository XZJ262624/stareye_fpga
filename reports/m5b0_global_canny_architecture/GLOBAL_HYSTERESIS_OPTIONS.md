# 全局滞后算法和状态格式比较

设W为分类弱点集合、S为强点集合，图边为合法图像范围内八邻接。黄金结果是S可达的S∪W连通分量；弱路径可以任意长，纯弱无seed连通域为空。所有软件模型都直接输入冻结分类图，不重新实现NMS；11拒绝整job。

K为最终可达弱点数。A最多K+1全扫，B每个改变的双向轮至少增加1个弱点，最多K+1双向轮=2(K+1)全扫；均为保守有限上界，不是紧确最坏复杂度或某蛇形已达到绝对最坏的声称。K≤921599（至少1强）；无强图从全0直接稳定。

正确性证明：初始化只含S。每次新置1必须是W且相邻当前已置1，所以所有新增点确实有到S路径（可靠性）。更新不删除；有限图必停止。停止固定点若漏掉一条从S到某W的最短路径，取该路径第一个漏点，其前驱已保留且相邻，矛盾（完备性）。B两个方向执行相同局部谓词，只改变可见时刻；保留同样不变式，固定点相同。最终pair.changed=0是足够条件；实现可将优化提前停止放在以后，本轮所有流量包含完整零变化PAIR。

事件加速模型只用于软件实验：强点激活时刻0；所有邻接弱点首次扫时刻1（含比strong扫描rank更早的点）。弱u在奇数正向扫s激活时，rank(v)>rank(u)则邻接v可同s，否则s+1；偶数反向扫反之。该最早到达变换单调，heap最早扫描号松弛精确求激活时刻。它不是硬件将用BFS，也不是实测逐扫720p。全部3^9分类图把literal和event的每像素激活号、每扫changed计数及最终图比较，另31×19全部模式literal交叉校验；完整720p使用事件等价求解，并独立坐标BFS核对最终图。A大图扫描数用BFS最大最短弱路径距离+1推导，小图运行真正Jacobi。见 SOFTWARE_RESULTS.md。

评分为本项目适配的工程判断，5最好，不是测量。B最坏评分仍低，不能因推荐而隐藏超时。

详细位序：linear=y×1280+x。classification的AXI word=floor(linear/64)，bit[2(linear%64)+:2]为code；byte内先低2bit存较小x。mask word=floor(linear/128)，bit[linear%128]为edge。little-endian字节序需通过未来真实FIFO/IP端序测试绑定，不根据旧W0/R0 FIFO推断新打包器排列。

WSTRING16表示每字节写strobe，不是每2bit写掩码；不能用它独立更新同字节的单个分类。推荐方案完整帧顺序capture、整拍work重写且W!=R工作区，消除了按像素DDR RMW。若改BFS或随机tile局部写2bit/1bit，则必须引入cache原子合并/读改写与访问冲突仲裁，容量节省可能被随机效率抵消。reserved11、像素数不符、帧间配置不一致都使整帧失败。

行步长刚好16B对齐，不要按每行2048B填充（那会放大分类6.4倍、mask12.8倍）。新DMA必须可发短burst和4KiB拆分；旧固定128beat控制器不能原样接分类/工作图。最终结果复制到独立A/B，保留工作图可复用但不能直接把仍可能被迭代改写的work作为显示租约。若以后零拷贝，必须统一工作/结果池并形式化所有权，本轮不采用。
