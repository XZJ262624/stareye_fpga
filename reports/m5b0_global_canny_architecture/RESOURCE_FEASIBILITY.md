# Ti60资源估算与保守余量

实际M5A最终 `efinity/m5a_streaming_canny_i3/outflow/Ti60_Demo.place.rpt:21–31`：9425/60800 XLR、105/256 RAM、0/160 DSP；map.rpt:3398列105个EFX_RAM10。使用10,240bit/块的容量下限估算，实际深宽/端口/复制会增加块数，不能据容量上取整当作综合结果。

1/2/3行若要求各自独立并行端口，1b/2b实际通常至少1/2/3个块，而不是容量表共享1块。64×64 tile还需halo(66×66)、边界队列及双缓冲；2b66×66为1089B，容量仍1块但读写端口或pingpong可倍增。完整分类图180块+已有105=285>256；不能放片上。2份分类+2工作+2结果共720块容量下限，远超Ti60，DDR是必要条件。

推荐行引擎缓存：old current/next、new previous行，输出重排行及预取行，按至多5条1b行800B + 1条2b分类320B约1120B逻辑容量；为独立端口/方向/乒乓预留8～12RAM10。不是在片上存完整current。打包器按128bit整拍收集，changed归约不需要frameRAM。

|---|---:|---:|---|
|分类tap/元数据/打包与capture FIFO|1000～2500|13～16|约16KiB async FIFO容量下限13块；配置/端序/跨域额外逻辑|

|控制/descriptor/epoch/复位/监测|1200～3500|2～6|统计、CRC/计数、握手和错误状态；不需要DSP乘法|
|总目标|6000～16000|33～64|粗估上下限；不得据此写成实际映射用量|

按最高估算：XLR=9425+16000=25425（41.82%），空余35375；RAM=105+64=169（66.02%），空余87（33.98%）；DSP=0。保留至少20%总资源时上限为48640XLR、204RAM、128DSP；相对于M5A最多允许新增39215XLR、99RAM、128DSP。候选高端估算在该限内，但精确FIFO配置、仲裁资源、跨域复制、布线拥塞和频率必须后续验证。

16KiB快照FIFO在18.6MB/s活动产生速率下，满空理论缓冲0.881ms；任何实际水位、CDC迟延、未决burst和guard会缩短可容忍停服时间，不能把0.881ms当作可保证的共享DDR停服期限。已有视频FIFO只有8KiB级且数据不可停，必须先满足它们的实时约束。低频engine可自由停顿，不因此拖住相机/HDMI。

M5A已有setup/hold +0.194/+0.026ns为历史最终实况，新增拥塞可能影响窄hold。DDR/时钟/管脚/视频分辨率保持既有验收边界；新增设计必须独立综合、时序及CDC验证，本轮未开展。资源看起来可容纳不足以克服端口/安全地址/QoS阻断。
